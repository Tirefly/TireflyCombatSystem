# VFXStudio

Tirefly 本机 Web 特效工作台，当前为 **0.1 第一阶段 / Foundation**。独立运行，不依赖 Unreal Engine，不提供 UE5/Godot 插件或游戏运行 SDK。

## 启动

需要 Node.js >= 22.12.0、pnpm 12；本轮使用 Node 24.21.0、pnpm 12.6.0。首次在本目录执行（Windows PowerShell）：

~~~powershell
pnpm.cmd install --frozen-lockfile
pnpm.cmd run build
pnpm.cmd start
~~~

打开终端打印的地址，默认 **http://127.0.0.1:4317**。服务只监听回环地址，不向局域网开放。关闭终端会停止服务，页面未保存修改不会自动落盘。若端口占用，可在启动前设置：

~~~powershell
$env:VFX_PORT = '4318'
pnpm.cmd start
~~~

浏览器需要 WebGL 2，建议桌面 Chrome/Edge 并启用硬件加速；不承诺移动端和其他浏览器。本工具尚未做跨浏览器/GPU像素一致验证。

## 当前能力

- 左图层、中真实三维预览、底时间轴、右属性/AI 四区工作台，明暗主题与窄屏重排。
- 法阵、刀光、Impact 三个版本化程序化模板；模板生成独立工程，不联动已有作品。
- 环、放射线、空间粒子、弧形条带、核心光斑；增删、复制、显隐、Solo；适用图层的时间、变换、形状、运动、淡入淡出、颜色和混合等基础参数。
- 左/右拖动环绕可切换，另一键平移；滚轮距离、重置视角、工程内机位书签。
- 固定帧定位、播放暂停、首末帧、单帧步进和循环；工程范围采用半开区间，例如0.8s×60fps为0–47共48帧。
- 最多100步撤销/重做、本机保存/列表/重开、独立副本；未保存退出提醒、保存期间继续编辑状态保护、磁盘版本冲突拒绝。
- Ctrl+S 保存，Space 播放/暂停，Ctrl+Z / Ctrl+Shift+Z 撤销/重做。输入框内不接管播放与撤销快捷键。

**尚未实现：** 真实 AI 生成、素材文件导入与贴图编辑、PBR变体、关键帧曲线、模块自由组合、可编辑扫动轨迹/游戏录制轨迹导入、自定义模板保存、离线PNG/图集/视频/多机位烘焙、完整技术交接包。它们仍在后续阶段范围，当前UI不会伪造成功。刀光目前仅预制弧形条带，不代表完整拖尾功能已完成。

## 工程与安全

工程保存在工具目录的 **.local/projects/**（已忽略，不提交版本库），每份文件为带磁盘版本的JSON封装，包含权威特效定义和机位书签。无云端上传、无AI凭据。需要备份时先保存，再复制该目录；**不要在服务写入期间手动编辑文件**。

- schemaVersion=1；未知字段、非法数值、重复ID和无效时间区间拒绝，不做隐式类型转换或字段删除。
- 工程ID仅允许字母数字、下划线和短横线，不提供任意路径接口。
- Host/Origin/跨站策略与会话写令牌；服务重启后请刷新页面获取新会话。此防护不是多用户身份系统，不能直接暴露到公网。
- 同一服务内按ID串行保存、临时文件原子替换、磁盘版本乐观校验。不提供多进程并行写同一存储目录的保证；不承诺断电级持久化或崩溃恢复。
- 本阶段模块按time、seed、稳定图层ID解析求值；无历史物理积分。相同定义重访同帧可复现状态，不承诺跨GPU逐像素一致。复制粒子图层会获得新ID，因此拥有独立随机分布。
- Solo/选中、播放游标、鼠标键绑定为临时工作台状态；显隐与书签是工程数据。模板默认Unlit、无光照与色调映射。

## 源码布局

| 目录 | 职责 |
| --- | --- |
| src/shared | 类型、严格校验、独立模板 |
| src/engine | 解析时间求值、Three场景与相机、绘制资源生命周期 |
| src/client | React工作台、命令历史、状态与网络交互 |
| src/server | 回环API、受限工程存储 |
| openspec/changes/add-vfx-studio | 本工具提案、设计、阶段任务和验证记录 |

生产构建输出在dist/，依赖在node_modules/，均已忽略。所有源码为UTF-8无BOM与LF。

开发前端时先完成一次build，在一个终端设置VFX_DEV=1后启动服务，再用另一个终端执行pnpm.cmd dev。开发页为127.0.0.1:5173，API代理到4317；**这只影响本工具，不替换DSH GUI**。后端改动需重新编译并重启。

## 人工验证路径

1. 新建每个模板 → seek/播放/单步 → 左右环绕映射/滚轮/平移/重置与书签。
2. 修改图层数值与颜色 → 复制/显隐/Solo/删除 → 撤销重做；删除最后一层后再添加。
3. 修改工程名并保存 → 改动后打开原工程 → 确认丢弃 → 核对已保存参数；同一工程第二窗口保存后第一窗口保存应被拒绝。
4. 切换明暗主题、收窄窗口，核对独立滚动、表单焦点及错误提示。
5. 打开AI页，确认未配置说明，没有实际生成调用。服务不可用时保存失败不得清空编辑。

实际运行验证与剩余未测项记在[任务清单 Execution ledger](<openspec/changes/add-vfx-studio/tasks.md#execution-ledger>)，不把上述步骤列表当作通过证明。本轮经过生产构建、定向请求及真实浏览器检查；独立评审执行受阻，经批准改为主代理专项自审，**未经独立评审**。尚未验证WebGL故障、磁盘失败和多GPU兼容；工程列表当前跳过损坏文件，未提供修复界面。
