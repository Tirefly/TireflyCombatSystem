# 核心基线 · 统一时钟（Clock）

> **定位**：V2 五项核心基线之一（Entity / Instance / Clock / EventBus / NumericAggregator）。
> **回答什么问题**：**什么时候**。

**图例**：✅ 已裁决 ｜ ⚠️ 待审 ｜ ❓ 待调研

> **本文件只写最终设计与已裁决的架构。** 不写历史实现；Why Not 一律一句话。

## 1.1 战斗时钟与泵 ✅

### 1.1.1 形态

| 项 | 设计 |
|---|---|
| 时间表示 | 一个 `FTcsClock` 值类型，由系统持有 |
| 取时入口 | **唯一**。代码 MUST NOT 直接取 wall-clock |
| 泵点 | World Tick 的**头部**（`OnWorldTickStart`） |

> **Why Not 尾部**：Tickable 自 tick 在尾部，太晚——到期与冲洗都需要在当帧业务逻辑之前完成。

### 1.1.2 泵的四步序 ✅

```text
① 取步长
② 时钟推进
③ 事件派发冲洗
④ 到期堆 AdvanceTo
```

**顺序不可调换**：

| 约束 | 理由 |
|---|---|
| 时钟必须先推进 | 否则到期与冲洗都没有时间基准 |
| 冲洗须早于到期堆 | 到期回调内可以发布事件；冲洗在后会让这些事件多等一帧 |

### 1.1.3 不设 per-component tick ✅

> 周期行为全部由**到期堆 + 事件总线**驱动，MUST NOT 引入「每帧遍历所有实体/组件调 Tick」这一层。

**Why Not**：千级实体下逐组件 tick 是「每帧 N 次虚调用」，随实体数线性增长；而无 per-component tick 的帧成本 = **到期项数**。

### 1.1.4 时间源不设接口 ✅

> **不提供可注入的时间源抽象，直接给具体实现。**

**判据**（[01-定位与判据](../01-定位与判据.md) 铁律 2）：它是**策略插槽**不是倒置缝——没有任何宿主需要「换一种时间轴」，零替代实现 ⇒ 不建接口。

**暂停 / 缩放**属于 `FTcsClock` 的字段语义，**不构成**建时间源接口的理由。

## 1.2 到期堆 `FTcsExpiryHeap` ✅

### 1.2.1 形态

**最小堆 + 池化条目 + 惰性取消**。

```cpp
// 取消锚点（不含任何业务类型）
struct FTcsExpiryHandle
{
    int64 SlotId = 0;      // 0 = 无效

    bool IsValid() const { return SlotId != 0; }
};

class FTcsExpiryHeap
{
public:
    // 入堆：只登记「什么时候」与「到点做什么」。载荷由 OnDue 的捕获自带。
    FTcsExpiryHandle Push(double DueTime, TFunction<void()> OnDue);

    // 取消：即刻回收槽位，堆内残留条目出队时凭失效句柄跳过
    void Cancel(FTcsExpiryHandle Handle);

    // 推进：先换出全部到期条目，再逐条回调
    void AdvanceTo(double Now);
};
```

**接口里 MUST NOT 出现任何业务类型**：没有实体句柄、没有实例句柄、没有裸数字 ID。

### 1.2.2 核心纪律：先换出，再回调 ✅

```text
AdvanceTo(Now)：
    把到期的条目全部从堆里【换出】到临时列表
    再逐条回调
```

| Why Not 边遍历边回调 | 后果 |
|---|---|
| 成本无界 | 一次 `AdvanceTo` 被自激拉长 |
| 结果依赖实现 | 到期顺序变成「取决于新条目什么时候被插进来」 |

> **回调中新建的条目归下一拍**——帧成本有界，且结果与插入时序无关。

### 1.2.3 载荷由回调捕获自带 ✅

> **到期堆 MUST NOT 携带任何载荷，也 MUST NOT 告诉回调「是谁到期了」。** 回调通过捕获自带上文。

```cpp
// 消费者侧写法：只捕自己的句柄，其余从池里读
const FTcsBuffInstanceHandle Handle = Instance->Handle;
Heap.Push(DueTime, [Handle]()
{
    // 查不到怎么办是消费者自己的业务，堆不代劳
    if (BuffBucket.IsValid(Handle)) { BuffDomain::BroadcastPeriodic(Handle); }
});
```

> **`this` 不入捕获**：`[this, Handle]` 就是两个捕获物，已越过 §1.2.4 的预算。回调里用不上 `this`——`BuffBucket` 与 `BuffDomain` 是可通过句柄定位的静态 / 全局入口。

| # | 判据（一句话） |
|---|---|
| ① | 到期时要做的事完全由消费者决定，而它要的正好是它自己的句柄 |
| ② | 回调本来就知道自己是谁——堆再「告诉」一遍是多余的信息通道 |
| ③ | 通用载荷必然退化成裸数字或裸字节，等于把问题原封不动换了个类型 |

**三条 MUST NOT**：

| # | 条文 |
|---|---|
| ① | 堆的接口 MUST NOT 出现任何业务类型（句柄、ID、枚举） |
| ② | 条目 MUST NOT 持有 OwnerId 一类「归属」字段 |
| ③ | 堆 MUST NOT 为「查不到」提供任何统一信号 |

### 1.2.4 捕获预算 ✅

> **到期回调 MUST NOT 捕获超过一个句柄。** 需要更多上下文时，从那个句柄解析出的对象里读。

> **`TFunction` 的内联尺寸 MUST NOT 被当作设计前提。**

| 为什么不能依赖它 | 来源 |
|---|---|
| 尺寸是 `#ifndef` 可覆盖的 | `CoreDefines.h:46` |
| 内联存储可能整体关闭（全部转堆分配） | `Function.h:25`：未定义或为 0 ⇒ `TFUNCTION_USES_INLINE_STORAGE = 0` |
| 承载捕获物的是带虚析构的基类子对象 | `Function.h:73` + `Function.h:223`：判据是 `sizeof(OwnedObj)`，含 vptr |

⇒ **MUST 用编译期断言守住，MUST NOT 记录「上限是 N 字节」。**

```cpp
// 判据由实现自身的常量导出，不写外部字面量。
// TFunction_OwnedObject 住在 UE::Core::Private::Function，取用需带上完整命名空间
template <typename TCallable>
constexpr bool TcsExpiryCaptureFits()
{
    return sizeof(UE::Core::Private::Function::TFunction_OwnedObject<TCallable, false, false>)
         <= TFUNCTION_INLINE_SIZE;
}
static_assert(TcsExpiryCaptureFits<TCapture>(), "捕获物会退化成堆分配");
```

> **这段代码的可用性未经编译验证**：`TFunction_OwnedObject` 位于 `UE::Core::Private` 命名空间（`Function.h:36`），**Private 不是稳定的公开契约**。若它不可访问，替代方案是改为断言 `sizeof(TCapture) <= sizeof(TFunction<void()>)` 这类**结构性上界**，而不是精确判据。
> **MUST 在首次实现时实测**：这条断言的形态以「能被编译器接受且能挡住超限捕获」为准，本条裁决的是**必须有断言**，不是断言的具体写法。

⇒ **正确写法是捕获句柄、从对象里读其余字段**（实例本身持 `Entity` / `Source` 等归属），而不是把需要的字段一起捕进来。

> **Why Not 只写成建议**：这个分配**不可见**——无编译错误、无日志、无计数器，只能靠抓分配栈事后定位。
> **不包 `static_assert` 的注册口就是缺陷。**

### 1.2.5 已知边界 ✅

> **「帧对齐 + 取消窗口」是到期堆表达不了的。** 这是 V2 必须承认的边界。

动作游戏需要**与动画通知对齐的时刻**与**取消窗口**，绝对时刻到期不足以表达；该能力归属行为域，不是时钟域的扩展点。

## 已裁定（速查）

| 项 | 结论 |
|---|---|
| 唯一取时入口 | **是**，禁 wall-clock |
| 泵点 | **World Tick 头部** |
| 泵序 | **取步长 → 推进 → 冲洗 → 到期**，不可换 |
| per-component tick | **不设** |
| 时间源接口 | **不建**（策略插槽，零替代实现） |
| 到期纪律 | **先换出，再回调**；回调中新建的条目归下一拍 |
| 到期堆载荷 | **不携带任何载荷**；回调通过 `TFunction` 捕获自带上文 |
| 归属字段 | **删除**（`OwnerId` 一类字段 MUST NOT 存在） |
| 「查不到」信号 | **不提供**——属消费者业务 |
| 捕获预算 | **一个句柄**；判据 MUST 由实现常量导出并写成 `static_assert`，MUST NOT 记录「上限 N 字节」——`TFunction` 内联尺寸可覆盖、可关闭 |
| 到期堆的表达边界 | **帧对齐与取消窗口表达不了**，归行为域 |
