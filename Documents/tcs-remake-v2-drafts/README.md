# TCS-Remake V2 · 草稿区（族外）

> **本目录不属于 V2 指导总纲。**
>
> V2 正式文档在 `../tcs-remake-v2/`。本目录只放**未经裁决**的材料，供复盘与调研使用。

---

## 为什么隔离

V2 文档的唯一目的是「读完就能直接写 V2 代码」。一旦把未裁决内容、历史形态、调研过程混进去，后续实现者（尤其是 Agent）会把**过程**当成**结论**——这是上一轮 V1 被污染的同一种机理，只是发生在文档层。

因此：

| 内容 | 位置 |
|---|---|
| 已裁决的设计 | `tcs-remake-v2/` |
| 未裁决的草稿 / 调研 / 复盘 | **本目录** |

## 使用规则

1. **不得作为实现依据。** 本目录任何内容，未经逐条裁决并写入 `tcs-remake-v2/` 之前，MUST NOT 被当作 V2 设计。
2. **裁决后的内容移走。** 某条机制一旦裁决通过，就从草稿里**删掉**并写成正式文档——不留副本，避免两处不一致。
3. **本目录可以整目录删除**，不影响 V2 任何设计。
