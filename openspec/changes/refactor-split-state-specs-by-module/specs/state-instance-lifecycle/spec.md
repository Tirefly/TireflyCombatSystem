## REMOVED Requirements

### Requirement: 状态实例句柄

**Reason**: 本能力 7 条需求**逐条主语是 `TcsBuff`**（`FTcsBuffInstance` / `UTcsBuffSubsystem` 的施加、查询、移除与生命周期广播），没有一条描述共享层 `TcsState`。能力名沿用拆分前的 `state-*`，主语已随 `PLN-REFACTOR-1` Task 4 搬进 `TcsBuff` ⇒ 名字谎报主语（`ARCH-05` D-1）。

**Migration**: 需求全文已**逐字迁入** `buff-instance-lifecycle`（本变更的 `ADDED`，正文除能力名互引外无改动）。
